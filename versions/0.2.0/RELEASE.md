# Яблочный сад · 0.2.0

## Запуск

Открой `play.html` в браузере. Код, пиксельный шрифт, стили и рисунки уже внутри. ZIP содержит этот же файл и `dist/` для запуска через HTTP. Для пересборки из исходников используй `npm ci`, `npm test` и `npm run release` с Node.js 24.

## Управление

- Перетаскивай карту, чтобы осмотреть мир. Масштаб меняется колёсиком, щипком или кнопками в правом нижнем углу. Кнопка прицела возвращает камеру к саду.
- Нажми в свободное место внутри сада, чтобы посадить стартовый саженец. Нажимай на спелую яблоню для ручного сбора. Новые саженцы стоят 5 яблок.
- Купи «???» за 6 яблок. Картошка объяснит, как работает его друг. Подсказку можно вызывать повторно кнопкой с вопросительным знаком.
- Нажми на корзину или выбери перенос в лавке, затем укажи свободное место внутри сада. Ёжики направятся к новой позиции.
- Открой панель ёжиков, чтобы осмотреть помощников, нанять новых или изменить состав кучки. Опыт тратится в отдельном дереве улучшений.

## Правила этой сборки

Первый платный найм стоит 12 яблок, следующая цена умножается на 1,55 и округляется вверх. Помощники генерируются и сохраняются вместе с миром. Шляпы и необычные цвета выпадают примерно в 4–5% случаев, необычное имя — в 6%. Первый помощник получает перк, у последующих помощников перк появляется с вероятностью 30%. Индивидуальные характеристики отложены.

Пиксельная кириллица Orchard Pixel создана из свободной растровой гарнитуры X.Org 7x13B. Рамки, иконки, спрайты и векторная карта нарисованы в коде по референсам из ревью. Изображения из референсов не входят в сборку.

## Проверка

Прошли 12 тестов модели и камеры. Дополнительно проверены отрисовка стартового состояния и знакомства с Картошкой, компоновка панелей для узкого окна и кириллица в шрифте. Среда запретила запуск локального сервера. Управление мышью и касанием в браузере остаётся проверить.
