# Ёжиковый сад 0.7.1.1

- The bulk job assignment preview describes busy hedgehogs without naming features the player may not have discovered. Assignments still take effect as before.
- The global upgrade tree opens with all visible nodes inside the viewport. Keyboard focus follows nodes when zoomed in.
- The Android app checks for updates while open, retries temporary failures, and can check on demand from «Настройки».
- Removed the launch-screen animation button. The orchard animation follows the device’s reduced-motion setting.

Install the signed APK over 0.7.1 to keep your garden. This hotfix uses Android version code 700101.
