# Ёжиковый сад 0.7.2

- Recruit previews and hedgehog profiles recommend up to three jobs by matching stats and perks to workplaces in the current garden.
- Existing perks can improve market service, cargo carried on foot, tractor driving and refueling, workshop batches, mining, generator maintenance, lab research, watering, and training. Perk descriptions reveal related effects as those jobs become available.
- Factories keep running automatically. Assign a hedgehog with a crafting perk to «Настраивать фабрику» to speed up batches or increase yield.
- Mining bonuses are recorded when a cycle starts and survive resting, reassignments, and save reloads.

Install the signed APK over a previous release to keep the same garden. The Android version code is 700200.
