# Ёжиковый сад 0.7.2.1

- Added a small, animated Easter egg somewhere on the map. Hover or tap it to see who’s there.
- Gardens without a hedgehog receive step-by-step guidance, starting with planting and ending with the first helper. Highlighted targets and progress counters follow the player’s actions.
- Картошка’s tutorials now open in a dedicated dialog that dims the game while you read.
- Hedgehogs have more to say when they’re alone, chatting with a friend, or doing a job. The shared cooldown between chats dropped from 33 to 31 seconds.

Install the signed APK over a previous release to keep your garden. The Android version code is 700201.
