# Ёжиковый сад 0.7.1

- Redesigned the main menu with an animated orchard scene and a custom pixel-art logo for «Ёжиковый сад». Pause background motion from the menu or use your device’s reduced-motion preference.
- Added a browser favicon and mobile home-screen icons (`apple-touch-icon` and web app manifest).

## Saves and installation

Existing 0.6.0 and 0.7.0 browser and Android saves load in 0.7.1. On Android, install the signed APK over the installed app to retain local data.
