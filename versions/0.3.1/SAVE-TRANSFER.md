# Как перенести сохранение в 0.3.1

В **0.3.1** нажми на значок дискеты наверху. Кнопка «Скачать JSON» сохраняет сад в файл `orchard-save.json`. В другой копии игры открой это же окно, нажми «Выбрать JSON», проверь уровень и число яблок и нажми «Заменить текущий сад».

## Выгрузка из 0.3.0 и более ранних версий

1. Открой именно ту копию старой игры, где виден твой сад. Если играл в скачанном `play.html`, открывай исходный файл в том же браузере и профиле.
2. Открой консоль браузера через меню инструментов разработчика или клавишу **F12**. Введи код ниже и нажми **Enter**. Он читает сохранение игры из браузера и скачивает JSON.
3. Открой 0.3.1 и загрузи скачанный файл через значок дискеты.

```js
(() => {
  const save = [3, 2, 1]
    .map(version => localStorage.getItem('itmo-apple-orchard-v' + version))
    .find(Boolean);
  if (!save) throw new Error('В этой вкладке сохранение сада не найдено.');
  const url = URL.createObjectURL(new Blob([save], { type: 'application/json' }));
  const link = document.createElement('a');
  link.href = url;
  link.download = 'orchard-save.json';
  link.click();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
})();
```

Сохрани копию JSON, если хочешь вернуться к прежнему состоянию. Импорт заменяет текущий сад в открытой версии после подтверждения.
