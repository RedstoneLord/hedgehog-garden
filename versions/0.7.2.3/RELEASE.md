# Ёжиковый сад 0.7.2.3

- Снабженцы пополняют лавки между заказами. Для яблок, ягод и готовых продуктов есть отдельные отсеки.
- Близкие лавки делят поток покупателей. Плавная подсветка показывает зоны конкуренции, спрос в лавках и качество почвы для новых участков.
- Картошка предлагает цели от первых улучшений лавки до исследований. Можно выбирать цели и скрывать подсказку на карте.
- В хозяйстве можно ставить склады. Ёжики и тракторы привозят туда товары и забирают их для других доставок.
- Групповые назначения и сохранённые наборы получили отдельный экран с поиском, быстрым выбором и проверкой перед применением.
- Объявления об уникальных перках теперь на русском. Обновлены значки перков и усилено влияние характеристик. «Зоркий садовник» выпадает в пять раз реже.

Код версии Android — 700203.
